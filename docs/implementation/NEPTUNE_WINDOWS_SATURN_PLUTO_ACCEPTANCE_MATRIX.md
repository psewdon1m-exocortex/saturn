## 3. Первое реализованное изменение

В `FileService` добавлен `findChildExact`: проверяет активного parent folder, использует существующий indexed repository lookup и сохраняет точное совпадение legacy имени. Операции listing/PROPFIND Depth 1 по-прежнему перечисляют каталог, когда перечисление запрошено явно. Изменение устраняет перечисление ради поиска одного известного имени. Backend storage verification, upload publication, права и форматы профилей этим patch не меняются.
