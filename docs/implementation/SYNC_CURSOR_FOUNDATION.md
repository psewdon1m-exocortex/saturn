# Inactive authenticated cursor primitive

The unexported `packages/sync/src/sync-cursor.ts` provides bounded HMAC-SHA256 opaque positions for snapshot and feed. Default services, public routes and capabilities do not use it yet. This primitive authenticates a server-issued position; it does not enroll a root, establish writer coverage, create a coherent snapshot or prove current server state.

Each token binds the server/root/epoch/policy/binding identity and a fingerprint derived by a trusted route from current actor, credential and scope state. Verification requires that identity to be loaded and authorized again. Snapshot ID/cut/keyset position and feed position are distinct. Sequence strings retain exact signed-int64 values. The signing key is identified and independently rotatable; key bytes are copied and secrets never appear in the token.

Idle expiry and an immutable absolute lifetime are independently enforced. Renewal can extend the idle lease only inside the original absolute lifetime. It cannot resurrect an expired token. Maximum token/payload bytes, strict canonical representation, Unicode scalars and integer bounds are checked. Verification rejects duplicate or extra payload fields, alternate encodings, wrong scopes, binding changes and reversed positions. An in-process clock reversal or a clock earlier than token issuance fails closed; restart requires the service's separately qualified durable clock/lease checks.

The future service must additionally check the exact durable snapshot lease, READY state, retained journal floor, coherent cut, membership, all-writer guard and current authorization inside its bounded read transaction. Page commit/prefix evidence is required before signing an advanced position. Transport cancellation, lease expiration, snapshot retirement and restoration to a new epoch remain service gates; a successful MAC check does not replace them. No public caller may supply the authority fingerprint or signing key.
