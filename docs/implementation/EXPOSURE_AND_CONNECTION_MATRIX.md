# Exposure and connection matrix

Every listener and route must be implemented from this registry. `noindex` and
obscurity are publication metadata, never authorization.

## Route classes

| Surface | Direction | Exposure mode | Identity | Secret source | Default policy | Revocation / shutdown | Verification |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Owner Web UI/API | Internet -> Gateway | Public non-indexable | Owner session + MFA/passkey target | Runtime session keys | Auth required; private/no-store after auth | Invalidate sessions; disable listener at edge | Authorized and unauthorized external tests |
| Drop redeem/upload | Internet -> Gateway | Public non-indexable | Short-lived Drop code, then independent client cookie bound to one shared channel | HMAC pepper from runtime secret | Upload-only, bounded channel TTL/files/bytes; real-time channel queue | Revoke sessions and challenges | Brute force, cross-channel denial, no storage list/read/delete |
| Share routes | Internet -> Gateway | Public non-indexable | High-entropy share token; optional password | Token generated by Gateway | Resource-scoped read only | Revoke/expiry/trash/classification | Enumeration, Range and revoke tests |
| Telegram webhook | Telegram -> Gateway | Public non-indexable machine endpoint | Webhook secret + update identity | Runtime secret store | Exact method/body limits and dedupe | Rotate secret or switch to polling | Forged secret and replay tests |
| Backup API | Service -> Gateway | Private where possible; otherwise authenticated public API | Per-service token and optional mTLS/IP binding | One-time generated token; hash in DB | Create/continue/status own runs only | Disable/rotate service identity | Cross-service privilege tests |
| WebDAV | Device -> Gateway | Public non-indexable authenticated | Per-device token | One-time generated app password | Path/action scopes | Revoke device | Real-client and scope tests |
| Laboratory private assets | Laboratory -> Gateway | Private | Service token or short-lived signed grant | Runtime service identity | Exact asset scope | Rotate/revoke identity | Unauthorized asset tests |
| Laboratory public assets | Internet -> Gateway | Public; not indexable by default | None | None | Explicit public classification only | Reclassify or disable public delivery | Cache/Range and private-leak tests |
| Admin SSH | Operator -> host | Private | VPN/IAP/allow-list + SSH key | Operator key store | No root/password login | Remove key/network grant | Unauthorized external test |
| PostgreSQL | Internal only | Concealed | Service DB credential | Runtime secret file | No public listener | Rotate credential / stop network | Port scan from external vantage |
| Metrics/debug | Internal only | Concealed | Operator/service identity | Runtime configuration | No public route | Disable listener | External 404/unreachable test |
| Storage Box SFTP DEV | DEV Gateway -> Storage Box | Currently externally reachable for qualification | DEV sub-account credential | Local secret file, to be replaced by key | DEV namespace only | Rotate password/key | Host fingerprint and namespace tests |
| Storage Box SFTP PROD | PROD Gateway -> Storage Box | Private Hetzner path target | PROD sub-account SSH key | PROD runtime secret mount | PROD namespace only | Rotate key; main account offline | External reachability and break-glass drill |

The owner SPA allow-list at the edge is `/`, `/files`, `/files/*`, `/inbox`,
`/inbox/*`, `/shared`, `/trash` and `/settings`. These paths serve the same
private/no-store application shell so direct folder URLs and browser refresh do
not fall through to a public or API route.

## External providers

| Provider | Data sent | Data received | Owner | Failure behavior |
| --- | --- | --- | --- | --- |
| Hetzner Storage Box | Encrypted transport of user bytes and system objects | Stored bytes and filesystem metadata | Gateway | Queue/retry within bounds; never report incomplete upload as active |
| Telegram Bot API | Commands/status notifications without secrets | Updates from bound identity | Telegram supervisor | Backoff; degraded status; file operations remain available |
| Independent backup target | Encrypted Saturn backup | Restore material | Operator | Alert on freshness; Storage Box copy remains first recovery source |

## Bot/indexing policy baseline

- Owner UI, authentication, Drop, Share, WebDAV and API routes are excluded
  from sitemaps and machine-navigation files.
- Authentication and administrative responses use `Cache-Control: private,
  no-store` and `X-Robots-Tag: noindex, nofollow, noarchive` where applicable.
- No `llms.txt` or public API catalog is created for private Saturn surfaces.
- Public Laboratory wrapper pages require a separate page-type registry before
  becoming indexable.
